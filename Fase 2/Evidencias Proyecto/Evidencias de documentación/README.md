# Evidencias de documentación

Documentos Scrum de cada sprint del proyecto Plataforma Cosmopolitan (Sprint 0 a Sprint 5).

Cada sprint tiene su carpeta (`Sprint 0`, `Sprint 1`, ...) con los 9 documentos:

| Documento | Formato |
|---|---|
| Sprint Backlog | Excel |
| Burndown | Excel |
| Kanban Board | Excel |
| Impediment Log | Excel |
| Daily Meetings | Word |
| Registro de Reuniones con la Agencia | Word |
| Incremento Funcional | Word |
| Acta de Sprint Review | Word |
| Acta de Sprint Retrospective | Word |

También se incluye el Plan de Pruebas de la plataforma.
