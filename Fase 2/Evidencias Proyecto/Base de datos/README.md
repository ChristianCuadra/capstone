# Evidencias Proyecto · Base de datos

Documentación de la base de datos de la plataforma.

- El modelo de datos (diagrama E-R y diccionario de datos) está en [`Anexo-Modelo-de-Datos-Cosmopolitan.docx`](Anexo-Modelo-de-Datos-Cosmopolitan.docx), en esta misma carpeta.
- La estructura se define en los modelos de Django y sus migraciones, dentro de `plataforma/apps/*/migrations/`.
- La base de datos en producción está alojada en Supabase (PostgreSQL).
